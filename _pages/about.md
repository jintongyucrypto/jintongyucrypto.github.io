I am a Ph.D. candidate in Computer Science and Technology at Shanghai Jiao Tong University, advised by Prof. Dawu Gu. My research sits at the intersection of hardware security, cryptography, and AI-driven security analysis.

My recent work focuses on deep learning-based side-channel analysis, post-quantum cryptographic implementations, and privacy protection for AI agent memory systems. I am expected to graduate in 2027, and I am currently seeking postdoctoral positions.

## Research Interests

- Hardware security and applied cryptography
- Deep learning-based side-channel analysis
- Side-channel analysis on LLMs

## Selected Projects

- **AI agent memory protection:** Designed a hardware-backed privacy protection architecture for long-term agent memory, covering embedding inversion, privileged reads, cross-user leakage, and memory poisoning threats.
- **Cryptographic testing engine:** Led student development work for commercial cryptographic testing engines, including side-channel analysis software and post-quantum fault injection tooling.
- **LLM agent for cryptographic evaluation:** Built an applied LLM agent with fine-tuning, RAG, and tool use to automate cryptographic evaluation report generation.
